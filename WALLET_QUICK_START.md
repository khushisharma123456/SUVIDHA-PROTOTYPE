## 🎯 How to Use

### Access the Page
1. Click "Wallet & Rewards" in the sidebar (💳 icon)
2. Page loads with your current balance

### Redeem Points
1. Scroll to "Redeem Your Points" section
2. Choose a service card
3. Click "Use Points" or "Recharge Now" button
4. Follow the redemption dialog

### View Transactions
1. Go to "Transaction History & E-Statement"
2. Use month dropdown to select period
3. Click filter chips (All/Earned/Used)
4. Click "Download E-Statement" for CSV export

### Check Usage
1. Scroll to "Points Usage Breakdown"
2. See circular progress for each category
3. View percentage, points, and rupee value

### Learn to Earn
1. Go to "How to Earn More Points"
2. Read earning methods
3. Complete activities to earn points

## 💾 E-Statement Export

When you click "Download E-Statement":
- Creates CSV file
- Includes all transactions for selected period
- Shows balance summary
- Downloads automatically

CSV Format:
```
Wallet Transaction Statement
Period: current
Total Balance: 4000 points
Points Earned This Month: 850
Points Used This Month: 450

Date,Type,Description,Points
3/12/2026,EARNED,March electricity consumption was 15% below average,+75
3/10/2026,USED,Paid ₹850 electricity bill with points,-850
...
```

## 🐛 Troubleshooting

### Balance not updating
- Click the refresh button (↻) next to balance
- Reload the page

### Transactions not showing
- Check month filter
- Check type filter (All/Earned/Used)
- Try "All Time" option

### E-Statement not downloading
- Check browser download settings
- Allow downloads from the site
- Try different browser

### Redemption not working
- Check if you have enough points
- Ensure service is available
- Contact support if issue persists
